# Root cause analysis

1. Restate the symptom in one sentence, with the exact error text and time window.
2. Build a timeline of changes and events before the first symptom.
3. List hypotheses. For each, name the evidence that would confirm or rule it out.
4. Check the evidence provided. Mark each hypothesis confirmed, ruled out, or untested.
5. State the root cause only if it is confirmed. Otherwise say what is still unknown and the next diagnostic step.
6. Finish with: root cause, contributing factors, fix, prevention.

Never present a hypothesis as a fact.
