# Claude Skills for Support Engineering

Reusable Claude skills that capture how a senior support engineer works: structured root-cause analysis, knowledge-article writing and customer updates.

Each skill is a folder under skills/ with a SKILL.md containing a name, a description that tells Claude when to use it, and the instructions. To use one, zip its folder and add it in Claude's skills settings, or place it in your skills directory.

| Skill | Use it when |
|---|---|
| root-cause-analysis | You have an incident, error log or query plan and need to know why |
| knowledge-article | A case is closed and you want reusable documentation |
| customer-update | You need to reply to a customer about an escalation |
